# Le Critique project page

Project page for **Le Critique: Privileged Value Functions for LLM Reinforcement Learning**.

- Website: <https://privileged-value-functions.github.io/>
- Paper: <https://arxiv.org/abs/2608.16739>
- Code: <https://github.com/HyperPotatoNeo/prime-values>

The page is a static GitHub Pages site. It adapts the [RSA project page](https://rsa-llm.github.io/) and the [Nerfies template](https://github.com/nerfies/nerfies.github.io). Paper figures are sourced from arXiv v1.
